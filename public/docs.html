Run it

Local setup (2 min)

npm install
cp .env.example .env   # optional — demo runs with zero keys
npm start              # → http://localhost:3000

Zero-key mode uses mock PayPal orders + stub AI with identical API contracts. The header badge always shows which mode you’re in.

Ship it

Deploy

Cloudflare Pages (this site)

npx wrangler pages deploy public --project-name shopgenie

Static Pages hosting serves landing, tool, and docs. Without a backend the tool auto-switches to in-browser demo mode (seed catalog, localStorage ledger, mock captures) — same UI, same flow.

Full backend (Render)

New Web Service → npm install / npm start, set PAYPAL_CLIENT_ID, PAYPAL_CLIENT_SECRET, OPENAI_API_KEY. render.yaml included.
